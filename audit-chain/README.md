# Defense-Dossier audit-chain wrapper

Обёртка, добавляющая к демо Defense-Dossier второй слой аудита —
hash-chain поверх тех же листьев, что уже якорятся Merkle-деревом.
Демо (`defense_dossier_demo.py`) не изменено и не импортируется обёрткой.

## Файлы

- `audit_log_hardened.py` — укреплённая реализация AuditLog от Sonnet 5.5,
  копия байт-в-байт (sha256 сверен с оригиналом). Не править здесь:
  правки — в обёртке.
- `dossier_chain.py` — обёртка: `DossierChain` + `leaf_event()` +
  `verify` + алиасы `AuditLog`/`verify` для прогона через `effects_matrix.py`.
- `test_dossier_chain.py` — сквозной тест: демо-листья → цепь → Merkle →
  подмены → матрица 41/41.

## Зачем два слоя

- Merkle-дерево отвечает: «этот лист входит в батч, батч заякорен?».
- Цепочка отвечает: «в каком порядке добавлялись записи, менялась
  ли какая-то из них или их порядок после?».
- `verify_leaf_binding()` связывает слои: сверяет события цепи с листьями
  демо поле в поле. Пересборка цепи поверх подменённого содержимого
  проходит chain-verify, но ловится binding-проверкой.

## Использование

```python
from dossier_chain import DossierChain
from defense_dossier_demo import make_synthetic_leaves, build_merkle_tree

chain = DossierChain()
for leaf in make_synthetic_leaves():
    chain.append_leaf(leaf)
root = build_merkle_tree([l.leaf_hash() for l in leaves])[-1][0]
package = chain.anchor_package(root)  # {"merkle_root", "chain_head", "records"}
assert chain.verify() is None
assert DossierChain.verify_leaf_binding(chain.records(), leaves) is None
```

`anchor_package()` ничего не подписывает, не timestamp'ит и не якорит —
он только возвращает пару (корень, голова цепи) для существующих
адаптеров демо (mock ЭЦП/TSA/анкер или банковские реализации).

## Границы и честность

- События, не прошедшие проверку (подклассы, не-JSON, целые вне 64 бит,
  глубина > 64, текст > 1M), отклоняются при добавлении и не записываются.
  Обёртка ничего молча не приводит: приведение типов — исходный класс
  дефектов файла A.
- Одно исправление поверх укреплённой версии живёт в обёртке, а не в копии:
  лимит текста считается по ключам и значениям вместе (в самой укреплённой
  версии проверка стоит только в ветке строковых значений, и событие из
  одного огромного ключа проскакивает).
- Без внешнего anchor усечение хвоста и полная пересборка цепи не видны;
  хэш без секрета — не подпись. Это ограничения конструкции, а не баги.

Моки демо — заглушки, а не гарантии. Подпись (SyntheticSigner), метка
времени (SyntheticTSA) и публичный анкер (SyntheticAnchor) в демо —
синтетические заглушки вместо настоящих ЭЦП НУЦ РК, RFC 3161 TSA и
публичного анкера: они показывают форму интеграции, а не дают
криптографических гарантий. То же относится к цепочке: пока голова цепи
(chain head) не заякорена во внешнем доверенном месте (TSA, публичный
реестр), цепочка не защищает от полной пересборки — тот, кто может
переписать файл цепи, может пересчитать все хэши заново, и проверка
внутри файла этого не заметит. Внешний анкер — обязательное условие
доказательности, а не опция.
